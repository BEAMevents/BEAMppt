# BEAMppt

PowerPoint and Keynote show control for events: sets up Presenter View on the right screens, a stage timer, a phone remote, OSC and HTTP control, slide sync across several Macs, and Stream Deck support. By [BEAM Events](https://beamevents.com).

This repository only holds the **Mac installers and updates**.

## Download
Get the latest version from **[Releases](https://github.com/BEAMevents/BEAMppt/releases/latest)**:

- **BEAMppt-x.y.z.dmg**: open it and drag BEAMppt into Applications. Use this one for a first install.
- **BEAMppt-x.y.z-mac.zip**: the same app, used by BEAMppt to update itself.

Requires macOS 14 or later, on Apple silicon or Intel Macs.

BEAMppt isn't notarized by Apple yet, so the first time you open it macOS may block it: go to **System Settings → Privacy & Security** and click **Open Anyway**. When BEAMppt first runs, allow **Accessibility**, **Local Network** and control of PowerPoint/Keynote when asked.

## Updates
BEAMppt checks for updates in the background. When one is ready, its menu bar icon gets a green dot and the menu shows **Update x.y.z ready**. Click it, then **Install & Restart**. Updates never install while a slide show is running.
